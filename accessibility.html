Accessibility statement

Last updated 22 October 2026

We want as many people as possible to be able to use helpmap.uk, including on older phones, small screens and slow or no connection. This statement covers https://helpmap.uk.

What we have done

  • Every result is also shown as a text list, and “List only” hides the map entirely, so the map is never the only way to find a service.
  • Buttons and links are sized for touch (at least 44 pixels), text can be zoomed, and there is a light mode as well as the default dark mode.
  • Search results and messages are announced to screen readers through a live region, and controls have text labels.
  • The site is available in English and Welsh.
  • Saved results still show without a connection, with the date they were saved.

How we tested it

The site has been checked with automated browser tests on narrow phone screens (360 and 390 pixels wide) and a desktop screen (1440 pixels), in dark and light modes and offline, including touch-target sizes, text contrast and that nothing overlaps or moves unexpectedly. It has not yet had a formal audit against the Web Content Accessibility Guidelines (WCAG) 2.2 AA, and has not yet been tested by people using screen readers or other assistive technology.

Compliance status

Because it has not been formally audited, we cannot yet say the site fully meets WCAG 2.2 AA. We plan to arrange an audit and will update this statement.

Known limitations

  • The interactive map (map pins and clusters) is hard to use with a screen reader or keyboard alone. Please use the results list or “List only”, which contain the same information.
  • Information about each service comes from that service and other public sources, and may not always be in plain language.
  • Links to other organisations' websites and to Google Maps directions open sites we do not control.

Feedback and contact

If you find a problem or need information in a different format, please email hello@helpmap.uk. We aim to reply within 5 working days.

Enforcement

If you are not happy with how we respond, you can contact the Equality Advisory and Support Service (EASS).
